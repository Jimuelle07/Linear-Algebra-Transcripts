## Topics covered
- The three objects of linear algebra: scalars (single values), vectors (1-D arrays), matrices (2-D arrays). Physics vectors (magnitude + direction, drawn as arrows) vs. linear algebra, where vectors are "objects that act on a given space with a specified coordinate system"
- Fields of scalars: R, C, Q (the "space of floats" in CS; integers are avoided because you can't always divide) and F2, the binary field {0, 1}, where 1 + 1 = 0. Computers store a float like 1.4 as a binary string (e.g. 64-bit)
- n-vectors over F: ordered n-tuples written vertically, indexed from 1 (not 0 as in programming). x_i is the i-th component, and F^n is the set of all n-vectors. (√2, −1) is in R² but not in Q². A vector as a data variable (e.g. heights of 10 survey respondents)
- Vector addition and scalar multiplication (component-wise), the zero vector 0̂, the negative −x, and subtraction x − y = x + (−y). R³ example with x = (1, 2, −1), y = (3, 1, 2): 2(x + y) = 2x + 2y = (8, 6, 2)
- The 8 basic properties of vector operations: 4 for addition (commutative, associative, zero vector, negatives) and 4 for scalar multiplication (c(x + y) = cx + cy, (r + s)x = rx + sx, (rs)x = r(sx), so ×6 = ×2 then ×3). - Arrows (n = 2 or 3, the "dimension"): (3, 2) = 3 units right, 2 up, from any initial point; think of a vector as an action that translates the whole space. Standard position = tail at the origin. Vector sum = composing the two moves: the parallelogram rule (the diagonal; "resultant" in physics)
- Low vs. high dimensions: 4D and up can't be drawn; linear algebra studies spaces of arbitrary dimension. Scaling: c > 1 stretches, 0 < c < 1 contracts, c < 0 points the opposite way (answered by student)
- F2³ has 2·2·2 = 8 vectors, which are exactly the binary strings of length 3 (strings of length 30 live in F2³⁰)
- Linear combinations (e.g. 2x₁ − 3x₂ + 5x₃; all-zero coefficients give 0̂) and the span ⟨S⟩ = all linear combinations of S. Data view: a respondent is a data point (185 cm, ₱136,000/month, married = 1), a set of them is a dataset, and its span is the "information space"
